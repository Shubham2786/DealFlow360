# Coding Rules

These rules govern implementation quality, clarity, and discipline across all tasks.

1. **Follow Project Conventions**: Adhere to established style guides, naming conventions, and file organization patterns.
2. **Prioritize Simplicity & Maintainability**: Favor clear, readable code over clever, convoluted solutions.
3. **Avoid Unnecessary Dependencies**: Use native platform capabilities or existing libraries before introducing external dependencies.
4. **Eliminate Duplicated Logic**: Consolidate repetitive code into reusable functions, modules, or services.
5. **Keep Changes Strictly Scoped**: Modify only the code necessary to fulfill the assigned task. Do not perform drive-by refactoring or unrelated cleanup.
6. **Defensive Implementation**: Validate inputs at boundary interfaces and handle edge cases and errors gracefully.
