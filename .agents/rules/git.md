# Git Rules

These rules govern source control discipline, commit hygiene, and collaborative workflows.

1. **Focused Commits**: Ensure commits are atomic, self-contained, and describe a single logical change with clear commit messages.
2. **No Unrelated Modifications**: Do not stage or commit formatting, whitespace, or file changes unrelated to the assigned task.
3. **Respect Branches & Scope**: Operate strictly within the designated branch or worktree for the current task.
4. **Preserve Collaborative Work**: Never force-push over shared branches or overwrite colleagues' or other agents' commits without explicit authorization.
5. **No Secrets or Credentials**: Never commit passwords, API tokens, private keys, environment configuration secrets, or sensitive local files.
6. **Clean Working Tree**: Verify working tree cleanliness and run diff checks before committing or proposing code changes.
