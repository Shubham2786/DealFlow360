## How to use in this project
1. Determine mode: **README mode** (structure + copy + visuals) vs. **Asset-only mode** (pure SVG hero or diagrams).
2. For DealFlow360, emphasize its stateful domain graph (authentication → quotation → approval → fulfillment → subscription → invoice → payment).
3. Keep Markdown searchable and copyable; use pure SVG for diagrams and visual hierarchy.
4. Do not commit, push, or publish without explicit approval.

Advisory only — technical documentation accuracy takes precedence over aesthetic embellishment.
